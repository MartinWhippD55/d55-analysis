- **What:** Extend shared-lib/types.ts with data source entities (TemplateDataSource, SharedSectionDataSourceDependency entity types + records + AvailableDataSource/DataSourceColumn/SectionDataSourceDependency interfaces + SK aliases)
- **Why:** This is the shared type surface every downstream story imports. Until the entity types, record shapes, and interfaces land, US-02 (discovery), US-03 (data source API), US-04 (dependency tracking), US-05 (enrichment), and US-06 (frontend) cannot read or write attachments and dependencies consistently.
- **Done when:**
  - `TemplateDataSource` and `SharedSectionDataSourceDependency` are added to `ContractNoteEntityType`.
  - `TemplateDataSourceRecord` (`PK: TEMPLATE#{id}`, `SK: DATASOURCE#{db}#{table}`) and `SharedSectionDataSourceDependencyRecord` (`PK: SHARED_SECTION#{id}`, `SK: DATASOURCE_DEP#{db}#{table}`) record shapes are defined.
  - `AvailableDataSource`, `DataSourceColumn`, `TemplateDataSource`, and `SectionDataSourceDependency` interfaces are defined.
  - SK type aliases (`DataSourceSortKey`, `DataSourceDepSortKey`) are added and `ContractNoteDynamoDbRecord` is extended with them.
  - `shared-lib/types.ts` type-checks cleanly.

### Suggested approach

```typescript
interface AvailableDataSource {
  database: string;
  tableName: string;
  columns: DataSourceColumn[];
  location?: string;
}

interface DataSourceColumn {
  name: string;
  type: string;
}

interface TemplateDataSource {
  database: string;
  tableName: string;
  displayName: string;
  attachedAt: string;
  attachedBy: string;
}

interface SectionDataSourceDependency {
  database: string;
  tableName: string;
}
```
