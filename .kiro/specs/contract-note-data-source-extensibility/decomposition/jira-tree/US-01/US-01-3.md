- **What:** Configure Athena workgroup and S3 results bucket; grant the Project Role access to both
- **Why:** The render pipeline's enrichment state (US-05) executes Athena queries against subscribed data sources and needs a query execution context with an S3 results location. This stands up that workgroup and results bucket and grants the Project_Role access, then passes the Athena config to the data-source Lambdas as env vars.
- **Done when:**
  - An Athena workgroup for contract note queries is created/configured with an S3 results location.
  - The S3 results bucket exists and is wired as the workgroup's result configuration.
  - The Project_Role is granted access to the workgroup and to the S3 results location.
  - CDK synth/build passes; a trivial query runs in the workgroup and writes results to the bucket (integration check).

### Suggested approach

```typescript
const resultsBucket = new s3.Bucket(this, 'ContractNoteAthenaResults', {
  encryption: s3.BucketEncryption.S3_MANAGED,
  blockPublicAccess: s3.BlockPublicAccess.BLOCK_ALL,
});

const workgroup = new athena.CfnWorkGroup(this, 'ContractNoteWorkgroup', {
  name: 'contract-note-queries',
  workGroupConfiguration: {
    resultConfiguration: {
      outputLocation: `s3://${resultsBucket.bucketName}/results/`,
    },
  },
});

// Project Role can read/write results and use the workgroup
resultsBucket.grantReadWrite(projectRole);
```
