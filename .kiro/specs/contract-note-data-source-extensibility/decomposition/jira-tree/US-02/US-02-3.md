- **What:** Property tests for discovery (Property 1: only bryt_number tables discoverable; Property 11: new subscriptions immediately discoverable)
- **Why:** Locks in the two discovery invariants so filtering and subscription behaviour can't silently regress. It backs Property 1 and Property 11 from the design and hardens the `listAvailableDataSources()` contract used by US-03 and US-05.
- **Done when:**
  - A generator produces random Glue table schemas with and without a `bryt_number` column.
  - Property 1 holds: a table appears in `listAvailableDataSources()` if and only if it contains a `bryt_number` column.
  - Property 11 holds: a newly subscribed table is discoverable on the next call with no code change.
  - Tests run in CI and fail with a minimal counterexample when either property is violated.

### Suggested approach

```typescript
import fc from "fast-check";
import { listAvailableDataSources } from "../glue-catalog-client";

// Generator: random Glue table schemas, some with bryt_number, some without.
const columnArb = fc.record({
  name: fc.string({ minLength: 1 }),
  type: fc.constantFrom("string", "int", "bigint", "double", "boolean"),
});
const tableArb = fc.record({
  database: fc.string({ minLength: 1 }),
  tableName: fc.string({ minLength: 1 }),
  columns: fc.array(columnArb),
  hasBryt: fc.boolean(),
});

const withBryt = (t) =>
  t.hasBryt ? { ...t, columns: [...t.columns, { name: "bryt_number", type: "string" }] } : t;

// Property 1: only bryt_number tables are discoverable.
it("Property 1: discoverable iff table has a bryt_number column", async () => {
  await fc.assert(
    fc.asyncProperty(fc.array(tableArb), async (tables) => {
      const catalog = tables.map(withBryt);
      const result = await listAvailableDataSources({ catalog }); // inject fake catalog
      const expected = catalog.filter((t) => t.columns.some((c) => c.name === "bryt_number"));
      expect(result.map((r) => r.tableName).sort()).toEqual(
        expected.map((t) => t.tableName).sort(),
      );
    }),
  );
});

// Property 11: a newly subscribed bryt_number table shows up on the next call, no code change.
it("Property 11: new subscriptions are immediately discoverable", async () => {
  await fc.assert(
    fc.asyncProperty(fc.array(tableArb), tableArb, async (tables, extra) => {
      const before = tables.map(withBryt);
      const added = { ...withBryt({ ...extra, hasBryt: true }) };
      const after = [...before, added];
      const result = await listAvailableDataSources({ catalog: after });
      expect(result.some((r) => r.tableName === added.tableName)).toBe(true);
    }),
  );
});
```
