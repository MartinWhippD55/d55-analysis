- **What:** Declare routes in contract-note-foundation.ts: contract-note-data-sources root (+ {database}/{table}/columns), data-sources under templates/{templateId}, data-source-dependencies under shared-sections/{id}; extend ContractNoteApiRoutes with DataSourceRouteResources
- **Why:** All six handlers (US-03-2..7) bind to route resources declared centrally here; without the resources and the `DataSourceRouteResources` type, the `DataSourceApi` construct (US-03-8) has nothing to wire `LambdaIntegration`s onto.
- **Done when:**
  - A `contract-note-data-sources` root resource exists, with a `{database}/{table}/columns` child.
  - A `data-sources` collection resource is added under the existing `contract-note-templates/{templateId}` resource, with a `{database}/{table}` child for detach.
  - A `data-source-dependencies` resource is added under `contract-note-shared-sections/{sharedSectionId}`.
  - `ContractNoteApiRoutes` is extended with `DataSourceRouteResources` and populated by `createRoutes`.
  - `cdk synth` succeeds and the new resources appear in the API Gateway tree.

### Suggested approach

```typescript
// contract-note-foundation.ts — inside createRoutes
export interface DataSourceRouteResources {
  dataSources: apigateway.IResource;            // /contract-note-data-sources
  dataSourceColumns: apigateway.IResource;       // /{database}/{table}/columns
  templateDataSources: apigateway.IResource;     // /contract-note-templates/{templateId}/data-sources
  templateDataSource: apigateway.IResource;      // /{database}/{table}
  sharedSectionDeps: apigateway.IResource;       // /contract-note-shared-sections/{sharedSectionId}/data-source-dependencies
}

const dataSources = api.root.addResource('contract-note-data-sources');
const dsColumns = dataSources
  .addResource('{database}')
  .addResource('{table}')
  .addResource('columns');

const templateDataSources = templateById.addResource('data-sources'); // templateById = contract-note-templates/{templateId}
const templateDataSource = templateDataSources
  .addResource('{database}')
  .addResource('{table}');

const sharedSectionDeps = sharedSectionById.addResource('data-source-dependencies');

return {
  // ...TemplateRouteResources, SharedSectionRouteResources, RulesRouteResources
  dataSourceRoutes: { dataSources, dataSourceColumns: dsColumns, templateDataSources, templateDataSource, sharedSectionDeps },
};
```
