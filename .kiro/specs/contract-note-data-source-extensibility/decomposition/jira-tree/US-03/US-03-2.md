- **What:** Implement list-available handler (Glue client -> [{database, tableName, columnCount}])
- **Why:** Backs `GET /contract-note-data-sources`, the discovery entry point the frontend data sources panel (US-06) uses to show what a Business_User can attach. Depends on the Glue catalog client (US-02) and the Project Role trust policy (US-01).
- **Done when:**
  - `data-sources/list-available.ts` assumes the Project Role and calls the shared Glue client.
  - Only tables containing a `bryt_number` column are returned.
  - The response body is `[{ database, tableName, columnCount }]`.
  - AssumeRole failure returns 500 and Glue unreachable returns 503.

### Suggested approach

```typescript
// api/src/data-sources/list-available.ts
import { getGlueCatalogClient } from '@shared-lib/glue-catalog-client';

export const handler = async (): Promise<APIGatewayProxyResult> => {
  const glue = await getGlueCatalogClient(process.env.PROJECT_ROLE_ARN!); // assumes Project Role
  const tables = await glue.listBrytNumberTables();                        // filtered to bryt_number

  const body = tables.map((t) => ({
    database: t.database,
    tableName: t.tableName,
    columnCount: t.columns.length,
  }));

  return { statusCode: 200, body: JSON.stringify(body) };
};
// Response: [{ "database": "energy_prod", "tableName": "contracts", "columnCount": 14 }]
```
