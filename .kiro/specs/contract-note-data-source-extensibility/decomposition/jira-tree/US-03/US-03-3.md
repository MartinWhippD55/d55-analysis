- **What:** Implement get-columns handler (column names + types for a table)
- **Why:** Backs `GET /contract-note-data-sources/{database}/{table}/columns`, the column detail the section-variant field browser (US-07) uses when a user maps fields to a data source. Depends on the Glue catalog client (US-02).
- **Done when:**
  - `data-sources/get-columns.ts` reads `{database}` and `{table}` from the path and fetches the table via the Glue client (assuming the Project Role).
  - The response body is `[{ name, type }]` with the Glue/Athena type string (string, int, bigint, double, boolean, etc.).
  - A table not found in the catalog returns 404.

### Suggested approach

```typescript
// api/src/data-sources/get-columns.ts
export const handler = async (event: APIGatewayProxyEvent): Promise<APIGatewayProxyResult> => {
  const { database, table } = event.pathParameters ?? {};
  const glue = await getGlueCatalogClient(process.env.PROJECT_ROLE_ARN!);

  const t = await glue.getTable(database!, table!);
  if (!t) return { statusCode: 404, body: JSON.stringify({ message: 'Table not found' }) };

  const columns = t.columns.map((c) => ({ name: c.name, type: c.type }));
  return { statusCode: 200, body: JSON.stringify(columns) };
};
// Response: [{ "name": "bryt_number", "type": "string" }, { "name": "unit_rate", "type": "double" }]
```
