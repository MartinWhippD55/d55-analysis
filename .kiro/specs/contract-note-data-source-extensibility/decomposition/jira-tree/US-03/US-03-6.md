- **What:** Implement list-attached handler (query DATASOURCE records for a template)
- **Why:** Backs `GET /contract-note-templates/{templateId}/data-sources`, the read path the frontend data sources panel (US-06) renders and the other side of Property 2 (attachment round-trip). Depends on the shared types (US-01) for the projection.
- **Done when:**
  - `data-sources/list-attached.ts` queries `DATASOURCE` records on `PK = TEMPLATE#{templateId}` with `SK begins_with DATASOURCE#`.
  - Each record is projected to `TemplateDataSource` (database, tableName, displayName, attachedAt, attachedBy).
  - The response body is `TemplateDataSource[]` (empty array when none attached).

### Suggested approach

```typescript
// api/src/data-sources/list-attached.ts
export const handler = async (event: APIGatewayProxyEvent): Promise<APIGatewayProxyResult> => {
  const { templateId } = event.pathParameters ?? {};

  const { Items = [] } = await ddb.query({
    TableName: TABLE,
    KeyConditionExpression: 'PK = :pk AND begins_with(SK, :sk)',
    ExpressionAttributeValues: { ':pk': `TEMPLATE#${templateId}`, ':sk': 'DATASOURCE#' },
  });

  const dataSources: TemplateDataSource[] = Items.map((r) => ({
    database: r.database,
    tableName: r.tableName,
    displayName: r.displayName,
    attachedAt: r.attachedAt,
    attachedBy: r.attachedBy,
  }));
  return { statusCode: 200, body: JSON.stringify(dataSources) };
};
```
