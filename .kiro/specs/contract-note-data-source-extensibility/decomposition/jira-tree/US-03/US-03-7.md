- **What:** Implement list-shared-section-deps handler (query DATASOURCE_DEP records)
- **Why:** Backs `GET /contract-note-shared-sections/{sharedSectionId}/data-source-dependencies`, the read surface the Admin Portal uses to check a template has the data sources a shared section requires. Reads the `DATASOURCE_DEP` records written elsewhere; this story only exposes them.
- **Done when:**
  - `data-sources/list-shared-section-deps.ts` queries dependency records on `PK = SHARED_SECTION#{sharedSectionId}` with `SK begins_with DATASOURCE_DEP#`.
  - Each record is projected to `SectionDataSourceDependency` (database, tableName).
  - The response body is `SectionDataSourceDependency[]` (empty array when none tracked).

### Suggested approach

```typescript
// api/src/data-sources/list-shared-section-deps.ts
export const handler = async (event: APIGatewayProxyEvent): Promise<APIGatewayProxyResult> => {
  const { sharedSectionId } = event.pathParameters ?? {};

  const { Items = [] } = await ddb.query({
    TableName: TABLE,
    KeyConditionExpression: 'PK = :pk AND begins_with(SK, :sk)',
    ExpressionAttributeValues: {
      ':pk': `SHARED_SECTION#${sharedSectionId}`,
      ':sk': 'DATASOURCE_DEP#',
    },
  });

  const deps: SectionDataSourceDependency[] = Items.map((r) => ({
    database: r.database,
    tableName: r.tableName,
  }));
  return { statusCode: 200, body: JSON.stringify(deps) };
};
```
