- **What:** Implement Athena query executor (api/src/render/athena-client.ts): assume Project Role; run SELECT * FROM {db}.{table} WHERE bryt_number = ? LIMIT 1; parse rows; no rows -> empty, multiple -> first+warn, error -> throw
- **Why:** The executor is the lowest layer of the enrichment state — the `enrich-data-sources` handler (US-05-2) calls it once per attached data source. It reuses the Project Role assumption pattern from the Glue catalog client (US-02).
- **Done when:**
  - The client assumes the Project Role and runs `SELECT * FROM {db}.{table} WHERE bryt_number = ? LIMIT 1`, awaiting query completion.
  - The result set is parsed into a key-value map keyed by column name.
  - No rows returns empty; multiple rows uses the first row and logs a warning; an Athena error or timeout throws.

### Suggested approach

```typescript
// api/src/render/athena-client.ts
import { AthenaClient, StartQueryExecutionCommand, GetQueryExecutionCommand, GetQueryResultsCommand } from "@aws-sdk/client-athena";
import { assumeProjectRole } from "./project-role"; // reused from US-02 pattern

export async function queryByBrytNumber(
  db: string,
  table: string,
  brytNumber: string,
): Promise<Record<string, unknown>> {
  const creds = await assumeProjectRole();
  const athena = new AthenaClient({ credentials: creds, region: process.env.AWS_REGION });

  // Parameterised on bryt_number; LIMIT 1 — one row per customer.
  const sql = `SELECT * FROM ${db}.${table} WHERE bryt_number = ? LIMIT 1`;
  const { QueryExecutionId } = await athena.send(new StartQueryExecutionCommand({
    QueryString: sql,
    ExecutionParameters: [brytNumber],
    WorkGroup: process.env.ATHENA_WORKGROUP,
  }));

  // Poll GetQueryExecution until SUCCEEDED; throw on FAILED/CANCELLED or timeout (>30s).
  await awaitCompletion(athena, QueryExecutionId!);

  const results = await athena.send(new GetQueryResultsCommand({ QueryExecutionId }));
  const rows = parseRows(results); // header row + data rows -> Record<string, unknown>[]
  if (rows.length === 0) return {};              // no rows -> empty
  if (rows.length > 1) console.warn(`Multiple rows for ${brytNumber} in ${db}.${table}; using first`);
  return rows[0];
}
```
