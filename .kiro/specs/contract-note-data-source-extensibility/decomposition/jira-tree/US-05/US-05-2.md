- **What:** Implement enrich-data-sources handler (api/src/render/enrich-data-sources.ts): read template DATASOURCE records; none -> pass through; extract customerreference; query each source concurrently; merge under {table}.{column}
- **Why:** This is the enrichment state's business logic. It sits between `select-template` and `render-sections` (wired in US-05-3) and produces the enriched `ContractData` consumed by every section-render Map iteration and, downstream, by US-08 integration wiring.
- **Done when:**
  - The handler reads the template's `DATASOURCE` records from DynamoDB; when there are none it returns the event unchanged with no Athena calls.
  - It extracts the BrytNumber from `contractData.customerreference` and queries each attached source concurrently via the Athena client (US-05-1), assuming the Project Role once.
  - Each result is merged into `contractData` under `{tableName}.{columnName}`; zero rows leaves the namespace empty; an Athena error or timeout throws so the state routes to `handle-failure`.

### Suggested approach

```typescript
// api/src/render/enrich-data-sources.ts
import { queryByBrytNumber } from "./athena-client";
import { readTemplateDataSources } from "./data-source-types"; // US-01

interface SelectTemplateResult {
  contractData: Record<string, unknown> & { customerreference: string };
  template: { id: string };
  sections: unknown[];
  inputFile: string;
  contractSummary: unknown;
}

export async function handler(event: SelectTemplateResult): Promise<SelectTemplateResult> {
  const sources = await readTemplateDataSources(event.template.id); // DATASOURCE records
  if (sources.length === 0) return event; // no attachments -> pass through, no Athena (Req 1.7)

  const brytNumber = event.contractData.customerreference;

  // Queries issued concurrently; Project Role assumed once inside the client.
  const results = await Promise.all(
    sources.map(async (ds) => ({
      table: ds.tableName,
      row: await queryByBrytNumber(ds.database, ds.tableName, brytNumber),
    })),
  );

  const contractData = { ...event.contractData };
  for (const { table, row } of results) {
    contractData[table] = row; // merge under {table}.{column}; empty row -> empty namespace
  }
  return { ...event, contractData };
}
```
