- **What:** Wire the state into render-pipeline.ts: add EnrichDataSourcesHandler NodejsFunction, insert between selectTemplate and renderSections, add to handle-failure catch array, grant table read + Athena/AssumeRole
- **Why:** Wiring makes the enrichment state part of the running pipeline. Without it the handler (US-05-2) is never invoked. It also ensures enrichment failures route to the same `handle-failure` state as every other step.
- **Done when:**
  - An `EnrichDataSourcesHandler` `NodejsFunction` exists with the table read grant, Project Role assume permission, and Athena env config.
  - `enrichDataSources` is inserted in the chain between `selectTemplate` and `renderSections`.
  - The new state is added to the catch-registration array so it routes to `handle-failure`, and it is granted `props.table.grantReadData` plus Athena/AssumeRole permissions.

### Suggested approach

```typescript
// cdk/lib/contract-notes/render-pipeline.ts
const enrichDataSourcesHandler = new NodejsFunction(this, "EnrichDataSourcesHandler", {
  entry: "api/src/render/enrich-data-sources.ts",
  environment: {
    TABLE_NAME: props.table.tableName,
    PROJECT_ROLE_ARN: props.projectRoleArn,
    ATHENA_WORKGROUP: props.athenaWorkgroup.name,
  },
});
props.table.grantReadData(enrichDataSourcesHandler);
enrichDataSourcesHandler.addToRolePolicy(new PolicyStatement({
  actions: ["sts:AssumeRole"], resources: [props.projectRoleArn],
}));
enrichDataSourcesHandler.addToRolePolicy(new PolicyStatement({
  actions: ["athena:StartQueryExecution", "athena:GetQueryExecution", "athena:GetQueryResults"],
  resources: ["*"],
}));

const enrichDataSources = new LambdaInvoke(this, "EnrichDataSources", {
  lambdaFunction: enrichDataSourcesHandler,
  outputPath: "$.Payload",
});

// Insert between selectTemplate and renderSections.
const chain = parseInput
  .next(selectTemplate)
  .next(enrichDataSources)   // NEW
  .next(renderSections)      // Map — fans enriched ContractData to each render-section
  .next(stitch)
  .next(writeOutput);

// Register the new state on the shared handle-failure catch.
for (const state of [parseInput, selectTemplate, enrichDataSources, renderSections, stitch, writeOutput]) {
  state.addCatch(handleFailure, { resultPath: "$.error" });
}
```
