- **What:** Implement DataSourceService (list available, get columns, attach/detach, list attached, list shared-section deps) wired to the API Gateway endpoints
- **Why:** It is the single frontend client for the US-03 data source API. Both the Data Sources panel (US-06-2) and the picker dialog (US-06-3) call it, and it is exposed downstream for US-07 (field browser) and US-08 (shared section dependency checks).
- **Done when:**
  - `listAvailable`, `getColumns`, `listAttached`, `attach`, `detach`, and `listSharedSectionDeps` each call their endpoint with the correct URL, method, and body.
  - Responses are mapped to the US-01 shared types (`AvailableDataSource`, `DataSourceColumn`, `TemplateDataSource`, `SectionDataSourceDependency`).
  - `detach` surfaces the 409 in-use response (affected sections + variants) to the caller so the panel can drive its confirmation warning.
  - Failed requests surface an error rather than a stale/partial result.

### Suggested approach

```typescript
@Injectable({ providedIn: 'root' })
export class DataSourceService {
  constructor(private http: HttpClient) {}

  listAvailable(): Observable<AvailableDataSource[]> {
    return this.http.get<AvailableDataSource[]>('/contract-note-data-sources');
  }

  getColumns(database: string, table: string): Observable<DataSourceColumn[]> {
    return this.http.get<DataSourceColumn[]>(
      `/contract-note-data-sources/${database}/${table}/columns`);
  }

  listAttached(templateId: string): Observable<TemplateDataSource[]> {
    return this.http.get<TemplateDataSource[]>(
      `/contract-note-templates/${templateId}/data-sources`);
  }

  attach(templateId: string, database: string, table: string): Observable<TemplateDataSource> {
    return this.http.post<TemplateDataSource>(
      `/contract-note-templates/${templateId}/data-sources`, { database, table });
  }

  // 409 body carries the affected sections + variants; let callers show the detach warning.
  detach(templateId: string, database: string, table: string): Observable<void> {
    return this.http.delete<void>(
      `/contract-note-templates/${templateId}/data-sources/${database}/${table}`);
  }

  listSharedSectionDeps(sharedSectionId: string): Observable<SectionDataSourceDependency[]> {
    return this.http.get<SectionDataSourceDependency[]>(
      `/contract-note-shared-sections/${sharedSectionId}/data-source-dependencies`);
  }
}
```
