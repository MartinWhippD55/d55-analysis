- **What:** Extend template-edit component with a Data Sources panel (show attached; [+ Attach] picker; detach with confirmation warning if a variant references its fields; available regardless of DRAFT/PUBLISHED)
- **Why:** It is where the Business_User views and manages a template's data sources. It hosts the [+ Attach] entry point to the picker dialog (US-06-3) and the detach-with-warning flow, both backed by `DataSourceService` (US-06-1).
- **Done when:**
  - The panel lists the attached data sources for the current template with name and column count (via `listAttached`).
  - A [+ Attach Data Source] button opens the picker dialog; on close the panel refreshes.
  - Each attached source has a detach action; a clean detach removes it from the list.
  - When `detach` returns 409, the panel shows a warning listing the affected sections and variants and only proceeds on confirmation.
  - The panel and its actions are available whether the template is DRAFT or PUBLISHED.

### Suggested approach

```typescript
@Component({ selector: 'template-edit-data-sources-panel', templateUrl: './data-sources-panel.html' })
export class TemplateEditDataSourcesPanelComponent implements OnInit {
  @Input() templateId!: string;
  attached: TemplateDataSource[] = [];

  constructor(private dataSources: DataSourceService, private dialog: MatDialog) {}

  ngOnInit(): void { this.refresh(); }

  refresh(): void {
    this.dataSources.listAttached(this.templateId).subscribe(a => this.attached = a);
  }

  onAttach(): void {
    this.dialog.open(DataSourcePickerDialogComponent, { data: { templateId: this.templateId, attached: this.attached } })
      .afterClosed().subscribe(() => this.refresh());
  }

  onDetach(ds: TemplateDataSource): void {
    this.dataSources.detach(this.templateId, ds.database, ds.tableName).subscribe({
      next: () => this.refresh(),
      error: (err) => {
        if (err.status === 409) {
          // err.error lists affected sections + variants — confirm before re-detaching.
          this.confirmInUseDetach(ds, err.error);
        }
      },
    });
  }
}
```

```html
<!-- data-sources-panel.html -->
<header>
  <h3>Data Sources</h3>
  <button mat-button (click)="onAttach()">+ Attach Data Source</button>
</header>
<ul>
  <li *ngFor="let ds of attached">
    {{ ds.displayName }} ({{ ds.columns?.length }} columns)
    <button mat-icon-button (click)="onDetach(ds)">Detach</button>
  </li>
</ul>
```
