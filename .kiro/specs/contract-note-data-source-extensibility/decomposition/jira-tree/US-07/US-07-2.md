- **What:** Implement shared section attachment dependency check: on adding a shared section, read its DATASOURCE_DEP records; if the template is missing required sources, prompt to add them first
- **Why:** Delivers `frontend-component:shared-section-dependency-check` — stops a shared section being attached to a template that is missing a data source it relies on, so contract notes never render with unresolved fields. Enforces parent Requirement 4.3/4.4.
- **Done when:**
  - Adding a shared section reads its `DATASOURCE_DEP` records via `DataSourceService.listSharedSectionDeps`.
  - The required set is compared against the template's currently attached data sources; the missing set is `deps − attachments` keyed on `{database}#{tableName}`.
  - If the missing set is non-empty, the user is prompted to add the missing Data_Source(s) before the section can be attached; if empty, the add proceeds with no prompt.
  - A failed list-shared-section-deps call blocks the add with a retry prompt rather than attaching without a check.

### Suggested approach

```typescript
// shared-section-dependency-check: gate the add on missing data sources.
// listSharedSectionDeps wraps:
//   GET /contract-note-shared-sections/{sharedSectionId}/data-source-dependencies

interface SectionDataSourceDependency { database: string; tableName: string; }
interface TemplateDataSource { database: string; tableName: string; }

const key = (d: { database: string; tableName: string }) => `${d.database}#${d.tableName}`;

async checkBeforeAttach(sharedSectionId: string, templateId: string): Promise<AttachDecision> {
  const deps = await this.dataSourceService.listSharedSectionDeps(sharedSectionId); // DATASOURCE_DEP records
  const attached = await this.dataSourceService.listAttached(templateId);
  const attachedKeys = new Set(attached.map(key));

  const missing = deps.filter(dep => !attachedKeys.has(key(dep)));
  if (missing.length === 0) {
    return { canAttach: true, missing: [] }; // no prompt (Property 6: prompt iff missing)
  }
  // prompt the user to add the missing Data_Source(s) first
  return { canAttach: false, missing };
}
```
