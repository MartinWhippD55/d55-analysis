- **What:** Integration tests: subscribe Glue table -> appears; attach -> drop XML -> enriched fields render; remove bryt_number -> filtered out; force Athena error -> handle-failure
- **Why:** Validates that discovery (parent Requirement 1) and render-time enrichment (parent Requirement 5) work as a whole through the deployed stack finalised in US-08-1, not just in isolated unit tests. Optional for a faster MVP, but it is the only check that exercises the wired Lambda→Project Role→Athena path end to end.
- **Done when:**
  - Discovery test: subscribing a Glue table in Unified Studio surfaces it in the available data sources list without code changes or redeployment (Requirement 1.3).
  - Filtering test: a subscribed table lacking a `bryt_number` column is filtered out of the available data sources list (Requirement 1.4).
  - Enrichment test: attaching a data source and dropping a matching XML drives the Render_Pipeline to populate the namespaced enriched fields and render them in the output PDF (Requirement 5.1).
  - Failure test: forcing an Athena error routes the Render_Pipeline to the existing `handle-failure` state (Requirement 5.6).
  - All four scenarios run against the deployed stack and pass.

### Suggested approach

```typescript
// Integration-test outline — four end-to-end scenarios against the deployed stack

describe('data source feature — end to end', () => {
  // 1. Discovery: subscribe -> appears (Req 1.3)
  it('surfaces a newly subscribed Glue table in the available list', async () => {
    await subscribeGlueTable('contract_note_enrichment_demo'); // Unified Studio subscription
    const available = await getAvailableDataSources();          // GET contract-note-data-sources
    expect(available.map(d => d.tableName)).toContain('contract_note_enrichment_demo');
    // no redeploy / code change between subscribe and assert
  });

  // 2. Filtering: remove bryt_number column -> filtered out (Req 1.4)
  it('filters out a table with no bryt_number column', async () => {
    await subscribeGlueTable('no_bryt_number_table');           // table without bryt_number
    const available = await getAvailableDataSources();
    expect(available.map(d => d.tableName)).not.toContain('no_bryt_number_table');
  });

  // 3. Enrichment flow: attach -> drop XML -> enriched fields render (Req 5.1)
  it('renders namespaced enriched fields in the output PDF', async () => {
    await attachDataSourceToTemplate(templateId, 'contract_note_enrichment_demo');
    const runArn = await dropContractXml('fixtures/contract-with-brytnumber.xml');
    const result = await waitForRenderPipeline(runArn);         // parse-input -> ... -> write-output
    expect(result.status).toBe('SUCCEEDED');
    const pdfText = await extractPdfText(result.outputKey);
    expect(pdfText).toContain(expectedEnrichedFieldValue);      // namespaced field from enrich-data-sources
  });

  // 4. Failure routing: force Athena error -> handle-failure (Req 5.6)
  it('routes to handle-failure when an Athena query errors', async () => {
    await forceAthenaError('contract_note_enrichment_demo');    // e.g. break workgroup/results perms
    const runArn = await dropContractXml('fixtures/contract-with-brytnumber.xml');
    const result = await waitForRenderPipeline(runArn);
    expect(result.lastState).toBe('handle-failure');            // enrich-data-sources catch array
  });
});
```
