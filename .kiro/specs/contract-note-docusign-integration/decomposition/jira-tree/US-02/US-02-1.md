- **What:** Salesforce OAuth client: read credentials from Secrets Manager, obtain/cache access token (client credentials flow), refresh before expiry
- **Why:** Every Salesforce call (contact lookup in US-02-2, upload in US-02-3) needs a valid access token. This is the foundation of the greenfield client and blocks the other sub-tasks.
- **Done when:**
  - Credentials (`salesforceOauthKey`, `salesforceOauthSecret`, `instanceUrl`, `tokenUrl`) are read from Secrets Manager secret `{resourcePrefix}contract-note/salesforce`.
  - A `POST /services/oauth2/token` (client credentials flow) obtains an access token that is cached in memory and reused across calls.
  - The token is refreshed before expiry rather than re-fetched on every request.

### Suggested approach

```typescript
// api/src/docusign/salesforce-client.ts
let cached: { token: string; expiresAt: number } | undefined;

async function authenticate(): Promise<string> {
  if (cached && Date.now() < cached.expiresAt - 60_000) {
    return cached.token;
  }
  const { salesforceOauthKey, salesforceOauthSecret, tokenUrl } =
    await readSecret(`${resourcePrefix}contract-note/salesforce`);

  const res = await fetch(tokenUrl, {
    method: 'POST', // POST /services/oauth2/token
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      grant_type: 'client_credentials',
      client_id: salesforceOauthKey,
      client_secret: salesforceOauthSecret,
    }),
  });
  const body = await res.json();
  cached = { token: body.access_token, expiresAt: Date.now() + body.expires_in * 1000 };
  return cached.token;
}
```
