- **What:** Signed document upload: ContentVersion + ContentDocumentLink, filename Contract-Note-{offerReference}-Signed-{date}.pdf, using the retry utility
- **Why:** The Webhook Lambda (US-06) calls this in the completion flow so the signed contract note lands back on the customer's Salesforce record, giving the sales team immediate access.
- **Done when:**
  - `uploadSignedDocument(salesforceRef, offerReference, pdfBuffer)` creates a ContentVersion via `POST /services/data/v58.0/sobjects/ContentVersion` with filename `Contract-Note-{offerReference}-Signed-{date}.pdf` and an appropriate content type.
  - It links the file to the record via `POST /services/data/v58.0/sobjects/ContentDocumentLink`.
  - Both calls are wrapped in the US-01 `withRetry` utility (3× exponential backoff); on final failure the error is re-thrown.

### Suggested approach

```typescript
import { withRetry } from 'shared-lib/retry'; // US-01

async function uploadSignedDocument(
  salesforceRef: string,
  offerReference: string,
  pdfBuffer: Buffer,
): Promise<void> {
  const token = await authenticate();
  const date = new Date().toISOString().slice(0, 10);
  const filename = `Contract-Note-${offerReference}-Signed-${date}.pdf`;

  await withRetry(async () => {
    // 1. Create the file
    const cv = await fetch(`${instanceUrl}/services/data/v58.0/sobjects/ContentVersion`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({
        Title: filename,
        PathOnClient: filename,
        VersionData: pdfBuffer.toString('base64'),
      }),
    });
    const contentDocumentId = await resolveContentDocumentId((await cv.json()).id, token);

    // 2. Link it to the customer record
    await fetch(`${instanceUrl}/services/data/v58.0/sobjects/ContentDocumentLink`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({
        ContentDocumentId: contentDocumentId,
        LinkedEntityId: salesforceRef,
        ShareType: 'V',
      }),
    });
  });
}
```
