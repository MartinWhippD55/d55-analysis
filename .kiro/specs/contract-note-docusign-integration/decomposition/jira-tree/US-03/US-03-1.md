- **What:** DocuSign JWT authentication: build assertion (integration key, impersonated user, scope), exchange for access token, cache + refresh before expiry
- **Why:** Every DocuSign call needs a valid access token. This is the entry point for the send flow (US-05) and unblocks envelope creation (US-03-2) and download (US-03-3). Caching avoids a token request on every call.
- **Done when:**
  - Credentials are read from Secrets Manager (`{resourcePrefix}contract-note/docusign`: `integrationKey`, `rsaPrivateKey`, `impersonatedUserGuid`, `accountId`, `authServer`).
  - A JWT assertion is built from the `integrationKey`, `impersonatedUserGuid`, and the signature scope, then exchanged for an access token via `POST /oauth/token` (the `docusign-esign` package handles the token exchange).
  - The token is cached and reused within its validity period, refreshing before expiry.
  - An authentication failure throws so the caller can log and halt.

### Suggested approach

```typescript
import * as docusign from 'docusign-esign';

let cachedToken: { accessToken: string; expiresAt: number } | undefined;

async function authenticate(secret: DocuSignSecret): Promise<string> {
  const now = Date.now();
  if (cachedToken && now < cachedToken.expiresAt - 60_000) {
    return cachedToken.accessToken; // reuse within validity window
  }

  const client = new docusign.ApiClient();
  client.setOAuthBasePath(secret.authServer); // e.g. account-d.docusign.com

  // docusign-esign builds the JWT assertion and exchanges it at POST /oauth/token
  const result = await client.requestJWTUserToken(
    secret.integrationKey,
    secret.impersonatedUserGuid,
    ['signature', 'impersonation'],
    Buffer.from(secret.rsaPrivateKey),
    3600,
  );

  const { access_token, expires_in } = result.body;
  cachedToken = { accessToken: access_token, expiresAt: now + expires_in * 1000 };
  return access_token;
}
```
