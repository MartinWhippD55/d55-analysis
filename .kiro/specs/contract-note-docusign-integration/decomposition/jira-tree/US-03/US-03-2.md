- **What:** Envelope creation: document (base64 PDF), signer recipient, signing tab, per-envelope Connect webhook, status 'sent'; return envelope ID
- **Why:** This is the core send capability the Send Envelope Lambda (US-05) invokes to dispatch the contract note PDF to the customer for signing. It depends on JWT auth (US-03-1).
- **Done when:**
  - An envelope definition is built from a `CreateEnvelopeRequest`: the contract note PDF as a base64 document, the customer (name + email) as the sole signer, and a `signHere` signing tab placed on the document.
  - A per-envelope `eventNotification` (DocuSign_Connect) webhook is configured pointing to the webhook endpoint.
  - The envelope status is set to "sent" and created via `POST /v2.1/accounts/{accountId}/envelopes`, returning the envelope ID.
  - Envelope creation failure throws with the contract note reference and Salesforce_Ref for the caller to log.

### Suggested approach

```typescript
import * as docusign from 'docusign-esign';

async function createEnvelope(req: CreateEnvelopeRequest, secret: DocuSignSecret): Promise<string> {
  const envelope: docusign.EnvelopeDefinition = {
    emailSubject: req.emailSubject,
    documents: [{
      documentBase64: req.pdf.toString('base64'),
      name: req.documentName,
      fileExtension: 'pdf',
      documentId: '1',
    }],
    recipients: {
      signers: [{
        email: req.customerEmail,
        name: req.customerName,
        recipientId: '1',
        tabs: { signHereTabs: [{ documentId: '1', pageNumber: '1', xPosition: '100', yPosition: '600' }] },
      }],
    },
    eventNotification: {
      url: req.webhookUrl, // per-envelope DocuSign Connect callback
      requireAcknowledgment: 'true',
      envelopeEvents: [{ envelopeEventStatusCode: 'completed' }],
    },
    status: 'sent', // triggers immediate email delivery
  };

  const apiClient = new docusign.ApiClient();
  apiClient.setBasePath(`${secret.authServer}/restapi`);
  apiClient.addDefaultHeader('Authorization', `Bearer ${await authenticate(secret)}`);
  const envelopesApi = new docusign.EnvelopesApi(apiClient);

  try {
    const result = await envelopesApi.createEnvelope(secret.accountId, { envelopeDefinition: envelope });
    return result.envelopeId;
  } catch (err) {
    throw new Error(`Envelope creation failed for ${req.contractNoteRef} (${req.salesforceRef}): ${err}`);
  }
}
```
