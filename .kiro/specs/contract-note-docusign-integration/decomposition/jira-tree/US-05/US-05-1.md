- **What:** SendEnvelope task handler + contract-metadata extraction from the state payload; validate required fields (halt if missing); idempotency check by contract note S3 key
- **Why:** This is the entry point of the Send Envelope Lambda: it turns the state payload into validated inputs and guarantees exactly-once sending. Its metadata extraction and idempotency check are the precondition the US-05-2 orchestration builds on, and the whole handler is what US-08 wires as the `SendEnvelope` task.
- **Done when:**
  - The handler reads the render output location (`output.bucket`/`output.key`) and `contractMetadata` (`salesforceRef`, `offerReference`, `customerName`) from the state payload.
  - Required fields are validated; a missing or unusable `salesforceRef` (or absent metadata) is logged as a structured error and the handler halts without creating an envelope.
  - An idempotency lookup by `contractNoteS3Key` (the `output.key`) short-circuits when an `EnvelopeRecord` already exists, logging and returning without a send.
  - Validated `ContractMetadata` and the PDF location are passed through to the orchestration step.

### Suggested approach

```typescript
// api/src/docusign/send-envelope.ts
import type { ContractMetadata } from "../shared/docusign-types";
import { findByContractNoteS3Key } from "../metadata/metadata-service";

interface SendEnvelopePayload {
  output: { bucket: string; key: string };
  contractMetadata: { salesforceRef: string; offerReference: string; customerName: string };
}

export async function handler(payload: SendEnvelopePayload) {
  const { output, contractMetadata } = payload;
  const contractNoteS3Key = output?.key;

  const metadata = extractMetadata(contractMetadata);
  if (!metadata || !metadata.salesforceRef) {
    log.error("invalid_contract_metadata", { contractNoteS3Key });
    return; // halt, no envelope
  }

  const existing = await findByContractNoteS3Key(contractNoteS3Key);
  if (existing) {
    log.info("envelope_already_exists_skip", { contractNoteS3Key, envelopeId: existing.envelopeId });
    return; // idempotent skip
  }

  // hand off to orchestration (US-05-2)
  return orchestrateSend(output, metadata);
}

function extractMetadata(m: SendEnvelopePayload["contractMetadata"]): ContractMetadata | null {
  if (!m?.salesforceRef || !m?.offerReference || !m?.customerName) return null;
  return { salesforceRef: m.salesforceRef, offerReference: m.offerReference, customerName: m.customerName };
}
```
