- **What:** Property tests for the send flow (Property 1: trigger-to-envelope correlation / idempotency)
- **Why:** Property 1 (trigger-to-envelope correlation) is the safety-critical invariant of this story: one valid contract note PDF must yield exactly one envelope and exactly one metadata record, and a retried `SendEnvelope` task must never double-send. A fast-check property test exercises this across generated inputs rather than a few hand-picked cases. Optional — can be deferred for a faster MVP.
- **Done when:**
  - A fast-check property generates valid `ContractMetadata` + output locations and asserts the handler causes exactly one `createEnvelope` and one `createRecord` linking S3 key, Salesforce_Ref, and Envelope_ID.
  - A second run of the same invocation (simulating a task retry) with the record now present asserts no additional `createEnvelope` call is made (idempotency by `contractNoteS3Key`).
  - The test passes reliably across generated inputs (US-05 does not seed with a known counterexample).

### Suggested approach

```typescript
// api/src/docusign/send-envelope.property.test.ts
import fc from "fast-check";

const metadataArb = fc.record({
  salesforceRef: fc.string({ minLength: 1 }),
  offerReference: fc.string({ minLength: 1 }),
  customerName: fc.string({ minLength: 1 }),
});
const payloadArb = fc.record({
  output: fc.record({ bucket: fc.string({ minLength: 1 }), key: fc.string({ minLength: 1 }) }),
  contractMetadata: metadataArb,
});

test("Property 1: trigger-to-envelope correlation / no double-send on retry", async () => {
  await fc.assert(
    fc.asyncProperty(payloadArb, async (payload) => {
      const store = new FakeMetadataStore();
      const docusign = new FakeDocusign();

      // first invocation → exactly one envelope + one record
      await handler(payload, { store, docusign });
      expect(docusign.createEnvelopeCalls).toBe(1);
      expect(store.recordsFor(payload.output.key)).toHaveLength(1);

      // retry of the same task → idempotent skip, no second send
      await handler(payload, { store, docusign });
      expect(docusign.createEnvelopeCalls).toBe(1);
      expect(store.recordsFor(payload.output.key)).toHaveLength(1);
    }),
  );
});
```
