- **What:** Webhook request handler: HMAC validation (401 if invalid), parse event, route by status, return 200 to acknowledge
- **Why:** The `POST /docusign-webhook` entry point that secures DocuSign Connect callbacks and dispatches them; it gates and unblocks the completion (US-06-2) and declined/expired (US-06-3) flows.
- **Done when:**
  - `validateHmac` rejects an invalid signature: the handler returns HTTP 401 and logs the invalid request.
  - A valid request is parsed into a `DocuSignWebhookEvent` and routed by status (completed / declined / expired; voided out of scope).
  - An unknown envelope (no `getByEnvelopeId` record) logs a warning and returns HTTP 200.
  - A successfully routed request returns HTTP 200 to acknowledge receipt.

### Suggested approach

```typescript
// api/src/docusign/webhook.ts
export const handler = async (event: APIGatewayProxyEvent): Promise<APIGatewayProxyResult> => {
  if (!validateHmac(event)) {
    console.warn(JSON.stringify({ msg: "invalid webhook HMAC" }));
    return { statusCode: 401, body: "invalid signature" };
  }

  const parsed = JSON.parse(event.body ?? "{}") as DocuSignWebhookEvent;
  const { envelopeId, status } = parsed;

  const record = await getByEnvelopeId(envelopeId);
  if (!record) {
    console.warn(JSON.stringify({ msg: "unknown envelope", envelopeId }));
    return { statusCode: 200, body: "ok" };
  }

  switch (status) {
    case "completed":
      await handleCompleted(record, parsed); // US-06-2
      break;
    case "declined":
    case "expired":
      await handleDeclinedOrExpired(record, parsed); // US-06-3
      break;
    // voided is out of scope
  }
  return { statusCode: 200, body: "ok" };
};
```
