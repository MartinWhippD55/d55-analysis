- **What:** Completion flow: download signed PDF (retries) -> store in S3 -> upload to Salesforce (retries) -> update metadata; on final failure write to error bucket
- **Why:** The core post-signing action: it moves a `completed` envelope's signed PDF into S3 and Salesforce and records the outcome, delivering the value of the whole webhook story.
- **Done when:**
  - `downloadSigned` retrieves the signed PDF by envelope ID (retry 3× with exponential backoff) and it is stored in the `{resourcePrefix}signed-contract-notes` bucket under key `{salesforceRef}/{envelopeId}/signed-contract-note.pdf`.
  - `uploadSignedDocument` attaches the PDF to the Salesforce record identified by the Salesforce_Ref (retry 3× with exponential backoff).
  - `updateStatus("completed", { signedPdfS3Key })` records the terminal status and S3 key.
  - On final retry failure at any stage, `writeErrorRecord` writes to the error bucket under key `docusign/{timestamp}-{envelopeId}.json`.

### Suggested approach

```typescript
async function handleCompleted(record: EnvelopeRecord, event: DocuSignWebhookEvent) {
  const { envelopeId, salesforceRef } = record;
  const signedPdfS3Key = `${salesforceRef}/${envelopeId}/signed-contract-note.pdf`;
  try {
    const pdf = await downloadSigned(envelopeId); // US-03, retries 3x backoff
    await s3.putObject({
      Bucket: `${resourcePrefix}signed-contract-notes`,
      Key: signedPdfS3Key,
      Body: pdf,
    });
    await uploadSignedDocument(salesforceRef, pdf); // US-02, retries 3x backoff
    await updateStatus(envelopeId, "completed", { signedPdfS3Key }); // US-04
  } catch (err) {
    await writeErrorRecord(`docusign/${Date.now()}-${envelopeId}.json`, {
      envelopeId, salesforceRef, stage: "completed", error: String(err),
    });
    throw err;
  }
}
```
