- **What:** Declined/expired flow: update metadata with status + reason, write notification record to the error bucket
- **Why:** Handles the non-completion terminal states so operators are notified when a customer declines or lets a contract note expire, closing out the envelope lifecycle.
- **Done when:**
  - A `declined` event calls `updateStatus` with the declined status and decline reason (if provided).
  - An `expired` event calls `updateStatus` with the expired status.
  - `writeErrorRecord` writes a notification record to the error bucket under key `docusign/{timestamp}-{envelopeId}.json` containing the envelope ID, Salesforce_Ref, status, and timestamp.

### Suggested approach

```typescript
async function handleDeclinedOrExpired(record: EnvelopeRecord, event: DocuSignWebhookEvent) {
  const { envelopeId, salesforceRef } = record;
  const { status, reason } = event; // "declined" | "expired"

  await updateStatus(envelopeId, status, reason ? { reason } : {}); // US-04

  await writeErrorRecord(`docusign/${Date.now()}-${envelopeId}.json`, {
    envelopeId,
    salesforceRef,
    status,
    reason,
    timestamp: new Date().toISOString(),
  });
}
```
