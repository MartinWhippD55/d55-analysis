- **What:** Property tests for the webhook handler (Property 7: completed -> S3 + Salesforce; Property 9: declined/expired notification; Property 10: no partial state)
- **Why:** Property-based tests give confidence the webhook behaves correctly over random valid/invalid events, guarding the completion and declined/expired flows against partial-state regressions.
- **Done when:**
  - Property 7 holds: for any envelope reaching `completed`, the signed PDF is stored in `{resourcePrefix}signed-contract-notes` (key `{salesforceRef}/{envelopeId}/signed-contract-note.pdf`) AND uploaded to Salesforce.
  - Property 9 holds: for any `declined`/`expired` envelope, a notification record is written to the error bucket with the envelope details and status.
  - Property 10 holds: for any processing failure at any stage, no partial state is left (e.g. no PDF in S3 without a logged error), verified via `writeErrorRecord`.

### Suggested approach

```typescript
import fc from "fast-check";

// Property 7: completed -> S3 + Salesforce
it("completed envelope stores PDF in S3 and Salesforce", () =>
  fc.assert(fc.asyncProperty(completedEventArb, async (event) => {
    await handler(event);
    expect(s3PutSpy).toHaveBeenCalledWith(
      expect.objectContaining({
        Bucket: `${resourcePrefix}signed-contract-notes`,
        Key: `${event.salesforceRef}/${event.envelopeId}/signed-contract-note.pdf`,
      }));
    expect(uploadSignedDocument).toHaveBeenCalledWith(event.salesforceRef, expect.anything());
  })));

// Property 9: declined/expired -> notification
it("declined/expired writes notification to error bucket", () =>
  fc.assert(fc.asyncProperty(declinedOrExpiredEventArb, async (event) => {
    await handler(event);
    expect(writeErrorRecord).toHaveBeenCalledWith(
      expect.stringMatching(/^docusign\/\d+-.+\.json$/),
      expect.objectContaining({ envelopeId: event.envelopeId, status: event.status }));
  })));

// Property 10: failure -> no partial state
it("failure never leaves S3 without a logged error", () =>
  fc.assert(fc.asyncProperty(failingEventArb, async (event) => {
    await handler(event).catch(() => {});
    if (s3PutSpy.mock.calls.length > 0 && !uploadSignedDocument.mock.results.some(r => r.type === "return")) {
      expect(writeErrorRecord).toHaveBeenCalled();
    }
  })));
```
