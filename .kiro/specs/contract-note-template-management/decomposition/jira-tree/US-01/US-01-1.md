- **What:** CDK: DynamoDB table + PriorityIndex GSI, S3 buckets, API Gateway routes
- **Why:** This is the persistence and routing surface for the whole feature. Every downstream story attaches to it: US-02/03/04/05 attach handlers to the route surface and read/write the table, US-06 reads the table, GSI and both buckets, and the render pipeline writes error records. Nothing downstream can start until this infrastructure exists.
- **Done when:**
  - The `ContractNoteTemplates` DynamoDB table is provisioned with a PK/SK schema (String partition key, String sort key) accommodating the template, section, variant, shared-section, version, rule and change-log record shapes.
  - The `PriorityIndex` GSI is defined with a constant `ALL_TEMPLATES` String partition key and a numeric `priority` sort key, enabling a single query for all templates in priority order.
  - An S3 bucket for section/variant schema JSON is provisioned.
  - A separate S3 bucket for render error records is provisioned.
  - The API Gateway route surface (paths + integration placeholders) for the template, section and rules endpoints is declared, so US-02/03/04/05 can attach handlers without redeclaring the gateway.
  - CDK synth/assertion tests confirm the table, GSI, both buckets and the routes are declared.

### Suggested approach

```typescript
// CDK construct: foundation infrastructure for contract-note template management.
export class ContractNoteFoundation extends Construct {
  readonly table: dynamodb.Table;
  readonly schemaBucket: s3.Bucket;
  readonly errorOutputBucket: s3.Bucket;
  readonly api: apigateway.RestApi;

  constructor(scope: Construct, id: string) {
    super(scope, id);

    // Single-table design: PK = e.g. TEMPLATE#{templateId}, SK = e.g. METADATA
    this.table = new dynamodb.Table(this, 'ContractNoteTemplates', {
      partitionKey: { name: 'PK', type: dynamodb.AttributeType.STRING },
      sortKey: { name: 'SK', type: dynamodb.AttributeType.STRING },
      billingMode: dynamodb.BillingMode.PAY_PER_REQUEST,
    });

    // PriorityIndex GSI: constant ALL_TEMPLATES partition, numeric priority sort.
    this.table.addGlobalSecondaryIndex({
      indexName: 'PriorityIndex',
      partitionKey: { name: 'GSI_PK', type: dynamodb.AttributeType.STRING }, // 'ALL_TEMPLATES'
      sortKey: { name: 'priority', type: dynamodb.AttributeType.NUMBER },
    });

    this.schemaBucket = new s3.Bucket(this, 'SchemaJsonBucket');       // s3://{schema-bucket}/{sectionId}/schema.json
    this.errorOutputBucket = new s3.Bucket(this, 'RenderErrorBucket'); // render pipeline error records

    // Route surface only; handlers are attached by US-02/03/04/05.
    this.api = new apigateway.RestApi(this, 'ContractNoteApi');
    const templates = this.api.root.addResource('contract-note-templates');
    templates.addResource('reorder');                     // PUT reorder-templates
    const templateId = templates.addResource('{id}');     // GET/PUT/DELETE template
    templateId.addResource('rule');                       // GET/PUT template rule (US-05)
    const sections = templateId.addResource('sections');  // GET/POST sections
    sections.addResource('reorder');                      // PUT reorder-sections
    sections.addResource('{sectionId}');                  // DELETE remove-section
    const sectionResource = this.api.root
      .addResource('contract-note-sections')
      .addResource('{id}');
    sectionResource.addResource('schema');                // GET/PUT section schema
    // ...remaining section/version/variant paths per the design's route table.
  }
}
```
