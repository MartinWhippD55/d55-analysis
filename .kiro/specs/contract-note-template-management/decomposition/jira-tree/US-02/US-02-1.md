- **What:** list-templates handler (priority-ordered)
- **Why:** Backs `GET /contract-note-templates`. It is the read entry point for the whole feature — the frontend TemplateListComponent (US-08) renders this response, and it exercises the `PriorityIndex` GSI from US-01.
- **Done when:**
  - The handler queries the `PriorityIndex` GSI (GSI PK = `ALL_TEMPLATES`, sorted by `priority`) and returns all templates ordered by `priority` ascending.
  - Each returned template includes `name`, `description`, `sectionCount` and `priority`.
  - When no templates exist, the handler returns an empty collection (not an error) so the frontend can render an empty state.

### Suggested approach

```typescript
// GET /contract-note-templates
import { DynamoDBDocumentClient, QueryCommand } from "@aws-sdk/lib-dynamodb";

export const handler = async () => {
  const res = await ddb.send(new QueryCommand({
    TableName: process.env.TEMPLATES_TABLE,
    IndexName: "PriorityIndex",
    KeyConditionExpression: "gsiPk = :all",
    ExpressionAttributeValues: { ":all": "ALL_TEMPLATES" },
    ScanIndexForward: true, // priority ascending (1 = highest)
  });

  const templates = (res.Items ?? []).map((t) => ({
    templateId: t.templateId,
    name: t.name,
    description: t.description,
    sectionCount: t.sectionCount,
    priority: t.priority,
  }));

  return { statusCode: 200, body: JSON.stringify({ templates }) };
};
```
