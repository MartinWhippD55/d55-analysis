- **What:** create-template handler (validation, duplicate check, priority)
- **Why:** Backs `POST /contract-note-templates`. It is how every new template enters the system; the frontend "Create" action (US-08) calls it, and downstream section/rule editing (US-03/US-05) operates on templates created here.
- **Done when:**
  - Required fields (`name`, `description`) are validated; a missing field returns 400 with field-level validation errors identifying exactly the missing fields.
  - A `name` that duplicates an existing template returns a 409 error indicating the name is already in use.
  - On success, the handler writes a `TEMPLATE#{id}` / `METADATA` record with a generated UUID `templateId`, `priority` = count of existing templates + 1, `sectionCount` = 0, and `createdAt`/`updatedAt` ISO 8601 timestamps plus `createdBy` from the Cognito username.
  - Creating then fetching the template by id returns the same `name` and `description` (create round-trip).

### Suggested approach

```typescript
// POST /contract-note-templates
// Request body: { "name": string, "description": string }
export const handler = async (event) => {
  const body = JSON.parse(event.body ?? "{}");

  // 1. Validate required fields -> 400
  const missing = ["name", "description"].filter((f) => !body[f]);
  if (missing.length) {
    return { statusCode: 400, body: JSON.stringify({ errors: missing.map((field) => ({ field, message: "required" })) }) };
  }

  // 2. Duplicate name check -> 409
  const existing = await queryAllTemplates(); // PriorityIndex query
  if (existing.some((t) => t.name === body.name)) {
    return { statusCode: 409, body: JSON.stringify({ message: `Template name '${body.name}' is already in use` }) };
  }

  // 3. Lowest priority = count + 1
  const now = new Date().toISOString();
  const item = {
    PK: `TEMPLATE#${randomUUID()}`, SK: "METADATA",
    templateId: /* uuid */, name: body.name, description: body.description,
    priority: existing.length + 1, sectionCount: 0,
    createdAt: now, updatedAt: now, createdBy: usernameFrom(event),
    gsiPk: "ALL_TEMPLATES",
  };
  await ddb.send(new PutCommand({ TableName: process.env.TEMPLATES_TABLE, Item: item }));
  return { statusCode: 201, body: JSON.stringify(item) };
};
```
