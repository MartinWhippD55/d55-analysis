- **What:** get/update/delete-template handlers
- **Why:** Backs `GET /contract-note-templates/{id}`, `PUT /contract-note-templates/{id}` and `DELETE /contract-note-templates/{id}`. These are the per-template edit and removal operations the frontend Edit/Delete actions (US-08) call. Delete must cooperate with US-03 (section records) and US-05 (shared sections).
- **Done when:**
  - GET fetches by `TEMPLATE#{id}` / `METADATA` and returns the metadata, or 404 if not found.
  - PUT persists the updated `name` and `description` and bumps `updatedAt`; save-then-fetch returns the new values.
  - DELETE removes the template's `METADATA` and its template-owned `SECTION#` records, does NOT delete shared sections referenced by the template, and re-compacts the remaining templates' `priority` to contiguous 1..N-1.

### Suggested approach

```typescript
// GET /contract-note-templates/{id}
const key = { PK: `TEMPLATE#${id}`, SK: "METADATA" };
const { Item } = await ddb.send(new GetCommand({ TableName, Key: key }));
if (!Item) return { statusCode: 404, body: JSON.stringify({ message: "Template not found" }) };
return { statusCode: 200, body: JSON.stringify(Item) };

// PUT /contract-note-templates/{id}   body: { name, description }
await ddb.send(new UpdateCommand({
  TableName, Key: key,
  ConditionExpression: "attribute_exists(PK)", // -> 404 if absent
  UpdateExpression: "SET #n = :n, description = :d, updatedAt = :u",
  ExpressionAttributeNames: { "#n": "name" },
  ExpressionAttributeValues: { ":n": body.name, ":d": body.description, ":u": new Date().toISOString() },
}));

// DELETE /contract-note-templates/{id}
// 1. Query the TEMPLATE#{id} partition; delete METADATA + template-owned SECTION# records
//    (leave SHAREDSECTION reference records / shared sections intact).
// 2. Re-compact: query PriorityIndex, drop this template, rewrite remaining priorities 1..N-1.
```
