- **What:** shared section CRUD handlers + references
- **Why:** These back the `shared-sections-crud` endpoint behind the Shared Sections Library screen (US-08), letting common elements (headers, footers, T&Cs) be reused across templates. Reference tracking here is what US-03-1 uses when a shared section is added to a template, and what protects against orphaning on delete.
- **Done when:**
  - `list-shared-sections` returns all shared sections (including T&C) each with a reference count.
  - `create-shared-section` and `update-shared-section` create/update a `SHARED_SECTION#{id}` / `METADATA` record, including the `isTermsAndConditions` designation.
  - `get-shared-section-refs` returns exactly the templates that reference the shared section (from its `REF#{templateId}` records).
  - `delete-shared-section` blocks with a 409 and returns the referencing templates when one or more references exist; deletes cleanly otherwise.

### Suggested approach

Reference count is a query over the `SHARED_SECTION#{id}` partition's `REF#` records; delete is guarded by it:

```typescript
// DELETE /contract-note-sections/shared/{id}
export async function deleteSharedSection(sectionId: string) {
  const refs = await query({
    PK: `SHARED_SECTION#${sectionId}`,
    skBeginsWith: 'REF#',
  });
  if (refs.length > 0) {
    return {
      statusCode: 409,
      body: {
        error: 'Shared section is referenced by one or more templates',
        referencingTemplates: refs.map(r => r.SK.replace('REF#', '')),
      },
    };
  }
  await deleteItem({ PK: `SHARED_SECTION#${sectionId}`, SK: 'METADATA' });
  return { statusCode: 204 };
}

// GET /contract-note-sections/shared — each entry carries a reference count
export async function listSharedSections() {
  const sections = await queryByPrefix('SHARED_SECTION#', 'METADATA');
  return Promise.all(sections.map(async s => ({
    sectionId: s.sectionId,
    name: s.name,
    isTermsAndConditions: s.isTermsAndConditions,
    schemaS3Key: s.schemaS3Key,
    referenceCount: (await query({ PK: `SHARED_SECTION#${s.sectionId}`, skBeginsWith: 'REF#' })).length,
  })));
}
```

`get-shared-section-refs` returns the same `REF#` templates (with denormalised `templateName`) for the detail panel.
