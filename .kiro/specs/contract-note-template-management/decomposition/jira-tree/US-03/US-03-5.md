- **What:** template change log
- **Why:** These back the `template-changelog` endpoint so a Business_User can see what changed on a template and when. The write side is called by the mutating handlers in this story (section add/remove/reorder) and by the Template API (US-02) for metadata and rule changes; the read side feeds the change log view (US-08).
- **Done when:**
  - A change log entry is recorded on template modification (section add/remove/reorder, metadata update, rule update) with `changeType`, `description`, `createdAt` and `createdBy`.
  - `list-template-changelog` returns the chronological list of changes for a template, newest first.
  - `changeType` uses the defined values: `section-added`, `section-removed`, `section-reordered`, `metadata-updated`, `rule-updated`.

### Suggested approach

A shared writer used by every mutating handler, plus a newest-first list reader:

```typescript
type ChangeType =
  | 'section-added' | 'section-removed' | 'section-reordered'
  | 'metadata-updated' | 'rule-updated';

// called by section add/remove/reorder (US-03-1) and by template metadata/rule handlers
export async function recordChangeLog(
  templateId: string, changeType: ChangeType, description: string, user: string,
) {
  const createdAt = new Date().toISOString();
  await put({
    PK: `TEMPLATE#${templateId}`,
    SK: `CHANGELOG#${createdAt}`,
    changeType, description, createdAt, createdBy: user,
  });
}

// GET a template's change log, newest first
export async function listTemplateChangelog(templateId: string) {
  const items = await query({
    PK: `TEMPLATE#${templateId}`,
    skBeginsWith: 'CHANGELOG#',
    scanIndexForward: false, // CHANGELOG#{timestamp} descending
  });
  return items.map(i => ({
    changeType: i.changeType, description: i.description,
    createdAt: i.createdAt, createdBy: i.createdBy,
  }));
}
```

Note: the parent design does not expose a dedicated HTTP path for `list-template-changelog`; the change log is returned per template. TODO (spec gap): the route for `list-template-changelog` is not listed in the parent design's Section API endpoint table.
