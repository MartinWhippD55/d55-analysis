- **What:** variant rule get/save handlers (reuse validation)
- **Why:** Each variant is guarded by a Variant_Rule — a Specification evaluated at render time to decide whether that variant is the one to render. These handlers get and save that rule, reusing the shared `spec-validation` utility (US-01) so variant selection stays consistent with template selection rules. They depend on the variant records from US-04-2 and feed the first-match-wins evaluation in US-06 and the shared rule editor in US-09.
- **Done when:**
  - `get-variant-rule` (`GET /contract-note-sections/{id}/variants/{variantId}/rule`) returns the variant's `specification` tree (absent/empty for the default variant, which carries no specification).
  - `save-variant-rule` (`PUT /contract-note-sections/{id}/variants/{variantId}/rule`) validates the submitted `SpecificationNode` tree with `shared-lib:spec-validation` before persisting it to the variant record's `specification` attribute.
  - A malformed tree is rejected with HTTP 400 and errors identifying the incomplete nodes by path; a well-formed tree is saved (parent 19.7).
  - A missing section or variant returns a 404 not-found error.

### Suggested approach

```typescript
// PUT /contract-note-sections/{id}/variants/{variantId}/rule
// Request body is a SpecificationNode tree (shared-lib:types, US-01):
// {
//   "type": "AND",
//   "leftOperand": { "type": "EQUALS", "field": "offer.producttype", "value": "Fixed" },
//   "rightOperand": { "type": "IN", "field": "offer.region", "values": ["North", "South"] }
// }

import { validateSpecification } from 'shared-lib/spec-validation'; // US-01

export const saveVariantRule: Handler = async (event) => {
  const { id: sectionId, variantId } = event.pathParameters;
  const specification: SpecificationNode = JSON.parse(event.body);

  const errors = validateSpecification(specification); // reuse US-01 validator
  if (errors.length > 0) {
    // 400 with node-path errors. Exact envelope is illustrative — the design
    // specifies "validation errors with node paths" but not the wrapper shape.
    return badRequest({ errors }); // e.g. [{ path: "rightOperand", message: "IN node missing values" }]
  }

  await updateVariantSpecification(sectionId, variantId, specification);
  return ok({ variantId });
};

export const getVariantRule: Handler = async (event) => {
  const { id: sectionId, variantId } = event.pathParameters;
  const variant = await getVariant(sectionId, variantId);
  if (!variant) return notFound();
  return ok({ specification: variant.specification ?? null }); // null for the default variant
};
```
