- **What:** Property tests for publishing and variants
- **Why:** Optional property-based hardening for the publish/variant invariants the render pipeline (US-06) depends on. It guards against regressions in pinned-version handling, update-available computation and single-implicit-variant fallback. It can be deferred for a faster MVP.
- **Done when:**
  - fast-check property tests cover the properties owned by this story:
    - Property 31 — creating a new section version leaves every linked template's `pinnedVersionId` unchanged (no publish).
    - Property 32 — after publishing version V, every template linked to the section has `pinnedVersionId = V`.
    - Property 33 — `updateAvailable` is true if and only if a template's `pinnedVersionId` is older than the section's latest version.
    - Property 36 — a section with no variant records resolves to the section's own `schemaS3Key` (single implicit variant).
    - Property 35 — the persisted variant order and default are asserted here; render-time first-match-wins/default evaluation is exercised end-to-end in US-06.
  - The tests run in CI and pass.

### Suggested approach

```typescript
import fc from 'fast-check';

// Property 32: publish updates all linked templates.
test('publish sets pinnedVersionId = V on every linked template', () => {
  fc.assert(fc.property(
    fc.array(fc.record({ templateId: fc.uuid() }), { minLength: 1 }), // linked templates
    fc.uuid(),                                                        // chosen version V
    async (linked, versionId) => {
      const section = await seedSectionWithReferences(linked);
      await publishSectionVersion(section.id, versionId);
      const refs = await queryReferences(section.id);
      return refs.every((r) => r.pinnedVersionId === versionId);
    },
  ));
});

// Property 33: updateAvailable <=> pinned older than latest.
test('updateAvailable is true iff pinned version is older than latest', () => {
  fc.assert(fc.property(
    fc.array(versionIdArb, { minLength: 2 }),
    async (versions) => {
      const [latest, ...older] = sortDescending(versions);
      const section = await seedSection({ versions, latest });
      for (const pinned of [latest, ...older]) {
        const { updateAvailable } = await linkedTemplateFor(section, pinned);
        if ((pinned !== latest) !== updateAvailable) return false;
      }
      return true;
    },
  ));
});

// Also: Property 31 (create version leaves pinned unchanged),
//       Property 36 (no variants -> section's own schemaS3Key).
```
