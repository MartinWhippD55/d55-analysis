- **What:** PDF stitcher (pdf-lib)
- **Why:** This assembles the individual section PDFs into the single final contract note. It runs in the `Stitch` state after all Map-state section renders (US-06-3) succeed, and its output feeds `write-output` (US-06-6).
- **Done when:**
  - `lambda:stitch` concatenates the section PDF buffers in section order using pdf-lib, with T&C pages last (parent 13.1, 13.2).
  - The result is a single PDF whose page count equals the sum of the input PDFs' page counts (Property 25).
  - A stitching failure is logged with the template id and halts (failure record `stage: stitching`), producing no output.

### Suggested approach

```typescript
import { PDFDocument } from "pdf-lib";

export async function stitch(sectionPdfs: Uint8Array[]): Promise<Uint8Array> {
  const out = await PDFDocument.create();

  // sectionPdfs are already ordered by section order, T&C last.
  for (const bytes of sectionPdfs) {
    const doc = await PDFDocument.load(bytes);
    const pages = await out.copyPages(doc, doc.getPageIndices());
    pages.forEach((page) => out.addPage(page));
  }

  return out.save(); // page count == sum of inputs
}
```
