- **What:** Property tests: evaluation, variants, stitching, failure isolation
- **Why:** These validate the pipeline's correctness properties end to end. The task is optional and can be deferred for a faster MVP, but it is what proves the first-match, variant, stitching and failure-isolation guarantees hold for arbitrary inputs rather than just the examples in the unit tests.
- **Done when:**
  - fast-check property tests exist and pass for the properties this story validates:
    - Property 22 — first-match-wins template selection.
    - Property 23 — specification operator evaluation correctness (EQUALS / IN / LESS_THAN / MORE_THAN).
    - Property 24 — independent section rendering produces a non-empty valid PDF.
    - Property 25 — stitching preserves page count (output pages == sum of inputs).
    - Property 26 — XML-to-JSON parsing produces a structure containing all XML fields.
    - Property 27 — pipeline failure produces no output.
    - Property 34 — render resolves the pinned version, not the latest.
    - Property 35 — variant first-match-wins with default fallback.
    - Property 36 — a section with no variants uses its own schema.
    - Property 37 — no variant match and no default halts with no output.
    - Property 38 — per-section failure isolation and no partial output.

### Suggested approach

```typescript
import fc from "fast-check";
import { evaluateSpec } from "shared-lib/spec-evaluator";

// Property 23: EQUALS is true iff the field equals the value.
test("EQUALS matches iff field equals value", () => {
  fc.assert(
    fc.property(fc.string(), fc.string(), (field, value) => {
      const node = { operator: "EQUALS", field: "k", value } as const;
      expect(evaluateSpec(node, { k: field })).toBe(field === value);
    }),
  );
});

// Property 25: stitching preserves page count.
test("stitch page count equals sum of inputs", () => {
  fc.assert(
    fc.asyncProperty(fc.array(fc.integer({ min: 1, max: 5 })), async (counts) => {
      const pdfs = await Promise.all(counts.map(makePdfWithPages));
      const stitched = await PDFDocument.load(await stitch(pdfs));
      expect(stitched.getPageCount()).toBe(counts.reduce((a, b) => a + b, 0));
    }),
  );
});
```
