- **What:** <pdfme-designer> web component wrapping the React pdf-me Designer
- **Why:** This is the core of US-07 and the foundation for the schema in/out wiring in US-07-2. It gives US-09's SectionEditorComponent a framework-agnostic element to host, avoiding an Angular-React bridge library and isolating the React dependency.
- **Done when:**
  - A `<pdfme-designer>` custom element is registered and can be added to the DOM.
  - `connectedCallback` loads and mounts the React pdf-me Designer root inside the element.
  - `disconnectedCallback` unmounts the React root (no leaked React tree or listeners).
  - The designer supports text, multiVariableText and table schema types with field position (x, y), dimensions (width, height), font settings and alignment.
  - Unit tests cover the lifecycle: mount on connect, unmount on disconnect.

### Suggested approach

```tsx
// pdfme-designer.ts — custom element wrapping the React pdf-me Designer.
import { createRoot, type Root } from 'react-dom/client';
import { createElement } from 'react';
import { PdfmeDesigner } from './PdfmeDesigner'; // React component using @pdfme/ui Designer

export class PdfmeDesignerElement extends HTMLElement {
  private root: Root | null = null;

  connectedCallback(): void {
    // Mount the React Designer root when the element enters the DOM.
    this.root = createRoot(this);
    this.root.render(createElement(PdfmeDesigner, { host: this }));
  }

  disconnectedCallback(): void {
    // Unmount the React root when the element leaves the DOM.
    this.root?.unmount();
    this.root = null;
  }
}

customElements.define('pdfme-designer', PdfmeDesignerElement);
```
