- **What:** schema-json in / schema-save event out; on-demand bundle load
- **Why:** This is the attribute-in / event-out contract that lets US-09's SectionEditorComponent feed schema JSON from the Section API (US-03) into the designer and persist what comes back. Building it as a separate on-demand bundle keeps React out of the main Angular bundle until the section editor opens. Builds on the element lifecycle from US-07-1.
- **Done when:**
  - The component accepts a `schema-json` attribute/property and initialises the designer with that schema.
  - On save, the component dispatches a `schema-save` CustomEvent carrying the updated schema JSON.
  - The save/load round-trip holds (Property 15): valid schema JSON in produces an equivalent, well-formed schema JSON structure out.
  - Malformed incoming `schema-json` initialises an empty designer rather than crashing the host.
  - A bundle/mount failure surfaces a failure state the host (US-09) can use to show an error with retry.
  - The component is packaged as a separate bundle (React + pdf-me Designer) loaded on demand when the section editor opens.

### Suggested approach

```tsx
// Wire schema-json in and schema-save out inside the custom element.
export class PdfmeDesignerElement extends HTMLElement {
  static get observedAttributes() { return ['schema-json']; }

  private parseSchema(raw: string | null) {
    try {
      return raw ? JSON.parse(raw) : { schemas: [] };
    } catch {
      return { schemas: [] }; // malformed input -> empty designer, don't crash host
    }
  }

  private emitSave(schema: unknown): void {
    this.dispatchEvent(new CustomEvent('schema-save', {
      detail: schema, bubbles: true, composed: true,
    }));
  }
}
```

```json
// schema-save event detail — one schemas entry per page.
{
  "schemas": [
    [
      { "name": "customerName", "type": "text", "position": { "x": 20, "y": 50 },
        "width": 150, "height": 12, "fontSize": 10, "fontName": "NotoSans",
        "alignment": "left" }
    ]
  ]
}
```
