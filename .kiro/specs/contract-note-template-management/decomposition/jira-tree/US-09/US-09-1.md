- **What:** TemplateListComponent (landing page)
- **Why:** This is the entry landing page for the whole admin area and the root of the component graph — it launches template edit, rules config, create and delete, and is the screen the US-10 portal sidebar entry routes into. Building it first unblocks TemplateEdit (US-09-2) and Navigation (US-09-7).
- **Done when:**
  - The component renders a table of templates via `TemplateService` showing name, description, section count and priority, ordered by priority ascending (parent 1.1, 1.2).
  - Reordering (drag-and-drop or up/down buttons) persists the new order through `TemplateService.reorder` and reverts to the previous order with an error notification if the call fails (parent 5.1, 5.2).
  - Row actions are present and wired: create, edit, delete, configure-rules (parent 2.1, 4.1, 10.1).
  - Delete prompts for confirmation before calling `TemplateService.delete` (parent 4.1).
  - An empty state message is shown when the list is empty (parent 1.3).
- **Backing endpoints:** `GET /contract-note-templates` (list, priority-ordered), `PUT /contract-note-templates/reorder`, `DELETE /contract-note-templates/{id}` — all via `TemplateService` (US-08).

### Suggested approach

```typescript
// template-list.component.ts — landing page, injects TemplateService (US-08).
@Component({ selector: 'app-template-list', templateUrl: './template-list.component.html' })
export class TemplateListComponent implements OnInit {
  templates: Template[] = [];      // Template DTO (US-01/US-08)
  loading = false;

  constructor(
    private templateService: TemplateService,
    private router: Router,
    private confirm: ConfirmDialogService,
  ) {}

  ngOnInit(): void { this.load(); }

  load(): void {
    this.loading = true;
    // GET /contract-note-templates -> Template[] ordered by priority ascending
    this.templateService.list().subscribe({
      next: (t) => { this.templates = t; this.loading = false; },
      error: () => { this.loading = false; /* toast + retry */ },
    });
  }

  create(): void { this.router.navigate(['/contract-notes/templates/new']); }
  edit(t: Template): void { this.router.navigate(['/contract-notes/templates', t.templateId]); }
  configureRules(t: Template): void { this.router.navigate(['/contract-notes/templates', t.templateId, 'rules']); }

  async delete(t: Template): Promise<void> {
    if (!(await this.confirm.ask(`Delete template "${t.name}"?`))) return;
    // DELETE /contract-note-templates/{id}; API re-orders remaining priorities
    this.templateService.delete(t.templateId).subscribe(() => this.load());
  }

  reorder(order: string[]): void {
    const previous = [...this.templates];
    // PUT /contract-note-templates/reorder — revert on failure
    this.templateService.reorder(order).subscribe({ error: () => (this.templates = previous) });
  }
}
```
