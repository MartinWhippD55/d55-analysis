- **What:** SharedSectionsComponent + detail
- **Why:** This is the second landing page of the admin area — the `SharedSectionsLibrary` where reusable sections (headers, footers, T&Cs) are managed independently of any one template. It is an entry point exposed by the navigation (US-09-7) and can run in parallel with the template list (both are wave-1 in this story's task graph).
- **Done when:**
  - The list renders all shared sections (name, type standard/T&C, reference count) via `SectionService` (parent 8.1, 9.1, 9.4).
  - Selecting a shared section shows a detail panel listing the templates that reference it (parent 8.3).
  - Create and edit are supported; editing a shared section creates a new version without changing any linked template's pinned version (parent 8.2 — publish is a separate action, US-09-6).
  - Deleting a referenced shared section is blocked/guarded: a warning lists the referencing templates and requires explicit confirmation (parent 8.4).
  - T&C shared sections are creatable and editable through the same section editor as other shared sections (parent 9.3).
- **Backing endpoints:** `GET /contract-note-sections/shared` (list), `POST /contract-note-sections/shared` (create), `PUT /contract-note-sections/shared/{id}` (update), `DELETE /contract-note-sections/shared/{id}` (delete with ref check), `GET /contract-note-sections/shared/{id}/references` (referencing templates) — via `SectionService` (US-08).

### Suggested approach

```typescript
// shared-sections.component.ts — SharedSectionsLibrary landing page.
@Component({ selector: 'app-shared-sections', templateUrl: './shared-sections.component.html' })
export class SharedSectionsComponent implements OnInit {
  sections: SharedSection[] = [];    // includes referenceCount
  selected?: SharedSection;
  references: SectionReference[] = [];

  constructor(private sectionService: SectionService, private confirm: ConfirmDialogService) {}

  ngOnInit(): void {
    // GET /contract-note-sections/shared -> SharedSection[] (name, isTermsAndConditions, referenceCount)
    this.sectionService.listShared().subscribe((s) => (this.sections = s));
  }

  select(s: SharedSection): void {
    this.selected = s;
    // GET /contract-note-sections/shared/{id}/references -> referencing templates
    this.sectionService.sharedReferences(s.sectionId).subscribe((r) => (this.references = r));
  }

  async delete(s: SharedSection): Promise<void> {
    if (s.referenceCount && s.referenceCount > 0) {
      const names = this.references.map((r) => r.templateName).join(', ');
      // parent 8.4: warn + list affected templates, require confirmation
      if (!(await this.confirm.ask(`"${s.name}" is used by: ${names}. Delete anyway?`))) return;
    }
    // DELETE /contract-note-sections/shared/{id} (server enforces ref check)
    this.sectionService.deleteShared(s.sectionId).subscribe(() => this.ngOnInit());
  }
}
```

```html
<!-- shared-sections.component.html -->
<ul>
  <li *ngFor="let s of sections" (click)="select(s)">
    {{ s.name }}
    <span>{{ s.isTermsAndConditions ? 'T&C' : 'Standard' }}</span>
    <span>{{ s.referenceCount }} refs</span>
    <button (click)="delete(s)">Delete</button>
  </li>
</ul>

<aside *ngIf="selected">
  <h3>Referenced by</h3>
  <div *ngFor="let r of references">{{ r.templateName }}</div>
</aside>
```
