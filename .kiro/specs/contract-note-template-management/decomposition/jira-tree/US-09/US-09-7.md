- **What:** Navigation + landing pages (page vs modal)
- **Why:** This ties the two landing pages together and enforces the page-vs-modal distinction: Template List and Shared Sections Library are full screens, while the section editor and version history are modals launched from within them. It depends on the list screens (US-09-1, US-09-5) and the template edit page (US-09-2), and it is the surface the US-10 portal sidebar entry routes into.
- **Done when:**
  - The navigation exposes entry points to the Template List and Shared Sections Library landing pages (parent 21.1, 21.2, 21.5).
  - Both entry points are gated by Cognito group membership and are hidden/blocked for users without the required group (parent 21.5, aligns with parent Requirement 15).
  - The Template List and Shared Sections Library render as full landing pages (routed views), not modals (parent 21.1, 21.2).
  - The section editor and section version history are presented as modal dialogs launched from within a landing page, not as standalone routes (parent 21.3).
  - Sections with multiple variants list those variants (rule summary, default indicator) within the template edit page rather than only inside a modal (parent 21.4).
- **Note:** The portal-level sidebar item that routes into this navigation is added in US-10; this sub-task delivers the in-module navigation entry points and route wiring.

### Suggested approach

```typescript
// contract-note-routing.module.ts — landing pages are routed; editor/history are modals.
const routes: Routes = [
  {
    path: 'contract-notes',
    canActivate: [CognitoGroupGuard],                 // parent 21.5: group-gated
    data: { requiredGroup: 'contract-note-admin' },
    children: [
      { path: 'templates', component: TemplateListComponent },        // landing page
      { path: 'templates/new', component: TemplateEditComponent },
      { path: 'templates/:id', component: TemplateEditComponent },    // hosts modals
      { path: 'templates/:id/rules', component: RulesConfigComponent },
      { path: 'shared-sections', component: SharedSectionsComponent },// landing page
      { path: '', redirectTo: 'templates', pathMatch: 'full' },
    ],
  },
];
// NOTE: SectionEditorComponent and SectionVersionHistoryComponent are intentionally
// NOT routes — they are opened via DialogService from within a landing page (parent 21.3).
```

```html
<!-- navigation.component.html — entry points, shown only to authorised users -->
<nav *ngIf="canAccess$ | async">
  <a routerLink="/contract-notes/templates">Contract Note Templates</a>
  <a routerLink="/contract-notes/shared-sections">Shared Sections Library</a>
</nav>
```
