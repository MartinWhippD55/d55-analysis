- **What:** CDK deployment wiring: IAM, S3-triggered state machine, API routes, CORS
- **Why:** This is the core of the integration story — without it the Lambda handlers, render state machine and buckets from the other stories exist but are not connected. It grants each function only the access it needs, connects the S3 input event to the pipeline, exposes the APIs to the portal, and unblocks the end-to-end tests (US-10-3).
- **Done when:**
  - Each Lambda (`template-handlers`, `section-handlers`, `variant-publish-handlers`, `rules-handlers`) and the `RenderStateMachine` is granted least-privilege IAM for the specific DynamoDB table and S3 buckets it uses (parent 14.1, 20.4).
  - Dropping an XML file into the configured S3 input bucket starts a `RenderStateMachine` execution via the S3 notification / EventBridge wiring (parent 14.1, 20.4).
  - Every API Gateway route is bound to the correct Lambda handler and CORS is configured for the Admin Portal origin so preflight requests succeed (parent 14.1).
  - CDK synth/assertion tests pass, asserting the IAM grants, the S3-to-state-machine notification, the route-to-handler bindings and the CORS configuration.

### Suggested approach

```typescript
// CDK stack that wires the feature together (least-privilege IAM, S3 trigger,
// API routes, CORS). Names match the parent design's resources.
export class ContractNoteTemplateStack extends Stack {
  constructor(scope: Construct, id: string, props: ContractNoteProps) {
    super(scope, id, props);

    const { table, schemaBucket, inputBucket, outputBucket, errorBucket } = props;

    // 1. Least-privilege IAM — grant only what each handler/state machine needs.
    table.grantReadWriteData(templateHandlers);
    schemaBucket.grantReadWrite(sectionHandlers);
    table.grantReadWriteData(variantPublishHandlers);
    // RenderStateMachine: read table + schema/input buckets, write output/error buckets.
    table.grantReadData(renderStateMachine);
    inputBucket.grantRead(renderStateMachine);
    outputBucket.grantWrite(renderStateMachine);
    errorBucket.grantWrite(renderStateMachine);

    // 2. S3 input event -> start a render execution (via EventBridge notification).
    inputBucket.enableEventBridgeNotification();
    new Rule(this, 'InputXmlDropped', {
      eventPattern: {
        source: ['aws.s3'],
        detailType: ['Object Created'],
        detail: { bucket: { name: [inputBucket.bucketName] } },
      },
    }).addTarget(new SfnStateMachine(renderStateMachine));

    // 3. Bind API Gateway routes to handlers + CORS for the portal origin.
    const api = props.existingApi; // existing Admin Portal API Gateway
    const templates = api.root.addResource('contract-note-templates', {
      defaultCorsPreflightOptions: {
        allowOrigins: [props.adminPortalOrigin],
        allowMethods: ['GET', 'POST', 'PUT', 'DELETE'],
      },
    });
    templates.addMethod('GET', new LambdaIntegration(templateHandlers)); // list-templates
    templates.addMethod('POST', new LambdaIntegration(templateHandlers)); // create-template
    // ...bind section, variant-publish and rules routes to their handlers likewise.
  }
}
```
