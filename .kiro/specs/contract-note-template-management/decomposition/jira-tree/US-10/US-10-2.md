- **What:** Portal sidebar navigation entry (Cognito-gated)
- **Why:** The Angular screens and `frontend-component:Navigation` from US-09 exist but are not reachable from the Admin Portal until they are surfaced. This adds the entry point so authorised Business Users can find the feature, and enforces that only users in the required Cognito group see it.
- **Done when:**
  - The Admin Portal sidebar shows a menu item that links to the template list route (parent 15.1).
  - The menu item's visibility is gated by Cognito group membership: users without the required group do not see it (parent 15.1, 15.3).
  - Manual verification confirms the item appears for a user in the required group and is hidden for one without it.

### Suggested approach

```typescript
// Add the sidebar entry, gated by Cognito group membership.
// Route target is the template list Landing_Page from US-09.
const contractNoteTemplatesNavItem: NavItem = {
  label: 'Contract Note Templates',
  route: '/contract-note-templates',
  // Only render when the signed-in user is in the required Cognito group.
  visibleWhen: (user: AuthenticatedUser) =>
    user.cognitoGroups.includes(CONTRACT_NOTE_TEMPLATE_ADMIN_GROUP),
};

// In the sidebar template, filter items by their guard before rendering:
// <a *ngFor="let item of navItems | filterVisible:currentUser" [routerLink]="item.route">
//   {{ item.label }}
// </a>
```
