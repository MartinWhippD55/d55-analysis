# Project Structure

This repository uses the following directory convention:

```
analysis/<CLIENT>/<PROJECT>/<TASK>/
```

Each task folder contains:
- `context.md` — background, summary, key areas, and current status
- `questions.md` — open and answered questions to track investigation state

When creating new task folders, use short kebab-case names that describe the work item.
